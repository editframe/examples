# Codex — Bug Fix Workflow

A 30-second product demo of the OpenAI Codex bug fix workflow.

**Built with the [Editframe](https://editframe.com) React SDK** · 1920×1080 · 30fps

---

## Quick start

```bash
npm install
npm run render
bash add-sfx-v16.sh        # mux music + SFX
```

The rendered video is saved to `output/`.

Audio files live in `audio/` and are fully cleared for commercial use — see [CREDITS.md](CREDITS.md) for license details.
