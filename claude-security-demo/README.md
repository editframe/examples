# Claude — Security Announcement

A 19-second editorial product demo announcing Claude's security public beta, with a slow-burn cinematic music bed.

**Built with the [Editframe](https://editframe.com) React SDK** · 1920×1080 · 30fps

---

## Quick start

```bash
npm install
npm run render
```

The rendered video is saved to `output/`.

Audio files live in `src/assets/` and are fully cleared for commercial use — see [CREDITS.md](CREDITS.md) for license details.
