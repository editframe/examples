# `audio/`

The music bed for this demo lives here. See [`../CREDITS.md`](../CREDITS.md) for provenance and license terms.

## Contents

| File | Type | Used in |
|---|---|---|
| `music-bed.mp3` | Music bed | Under the full ~20s (loudnorm −16, fade in/out) |

This cut is **music only** — there are no sound effects in the timeline.

## Replacing audio

[`../add-audio.sh`](../add-audio.sh) expects `music-bed.mp3`. Drop a replacement with the same
filename and re-run it (or edit the `MUSIC=` variable near the top). When you swap a file,
update [`../CREDITS.md`](../CREDITS.md) with the new source so downstream forkers can verify provenance.
