## Audio

No audio files are bundled in this release. The render at `output/demo.mp4` is silent.

When ready to add audio:

1. Source a royalty-free music bed from [Pixabay Music](https://pixabay.com/music/) or [Free Music Archive](https://freemusicarchive.org/).
2. Source SFX from [Pixabay SFX](https://pixabay.com/sound-effects/) or [Freesound.org](https://freesound.org/) (filter CC0).
3. Write an `add-sfx-v1.sh` bash script using `ffmpeg adelay` to layer cues frame-accurately.
4. Document each file in this CREDITS.md with title, artist, source URL, and license.
