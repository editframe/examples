# `audio/`

**Audio is a future pass for this project.** The files in this directory are inherited from the template and are NOT used in the current render.

When adding audio to this project:

1. Source a royalty-free music bed and place it here as `music-bed.mp3`
2. Source any SFX and place them here
3. Write an `add-sfx-v1.sh` at the repo root to layer them via `ffmpeg`
4. Document all sources in `../CREDITS.md`

See `../CREDITS.md` for guidance on royalty-free audio sources.
