# Claude Code — Financial Services

A 30-second product demo of Claude Code agent templates for financial services.

**Built with the [Editframe](https://editframe.com) React SDK** · 1920×1080 · 30fps

---

## Quick start

```bash
npm install
npm run render
```

The rendered video is saved to `output/`.

Audio files live in `src/assets/` — see [CREDITS.md](CREDITS.md) for provenance/license details.
