# Scoup — Editorial Product Video

A 37-second glassmorphic editorial product video for Scoup, showcasing GSAP, AnimeJS, and Three.js through the Editframe React SDK.

**Built with the [Editframe](https://editframe.com) React SDK** · 1920×1080 · 30fps

---

## Quick start

```bash
npm install
npm run render
```

The rendered video is saved to `output/`.
