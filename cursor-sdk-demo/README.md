# Cursor — SDK

A 25.3-second product demo of the Cursor SDK (light paper variant).

**Built with the [Editframe](https://editframe.com) React SDK** · 1920×1080 · 30fps

---

## Quick start

```bash
npm install
npm run render
```

The rendered video is saved to `output/demo.mp4` in one pass — music and keyboard SFX play as native `<Audio>` elements on the composition timeline, no post-render mux step.

Audio files live in `src/assets/` (music bed) and `src/assets/sfx/` (keyboard typing cues) and are fully cleared for commercial use — see [CREDITS.md](CREDITS.md) for license details.
