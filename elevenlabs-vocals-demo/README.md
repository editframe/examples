# ElevenLabs — Vocals

A 25-second product demo for ElevenLabs Vocals — dark, teal-lit, motion-dense — HTML / CSS type and UI with ElevenLabs brand imagery.

**Built with the [Editframe](https://editframe.com) React SDK** · 1920×1080 · 30fps

---

## Quick start

From the examples repo root:

```bash
npm install
npm start
npm run render:elevenlabs-vocals-demo  # -> elevenlabs-vocals-demo/output/demo.mp4
```

The music bed plays as a native `<Audio>` element on the composition timeline — no post-render mux step. Audio lives in `src/assets/` — see [CREDITS.md](CREDITS.md) for license details.

---

## Scene timeline

| Time | Scene | What happens |
|---|---|---|
| `0 – 3.6s` | **Intro** | Image-sequence intro, stepped wordmark glyphs, faceted diamond sprite |
| `3.6 – 5.5s` | **Upload** | Upload-button sequence with three artwork thumbnails pulled in |
| `5.5 – 10.7s` | **Carousel** | Full-screen product-UI carousel (155 frames) |
| `10.7 – 11.9s` | **Songs** | Glowing song rows resolve with tree connector, transition sequence |
| `11.9 – 25.0s` | **AuroraFinale** | Recording modal, orb bloom, aurora stills, player pill, wipe to finale |
