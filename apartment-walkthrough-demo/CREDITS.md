# Credits

Built with the Editframe React SDK, React Three Fiber, Drei, Three.js, and postprocessing.

Bundled texture and environment assets are local demo assets used for the apartment walkthrough scene. The Poly Haven-derived assets and PBR textures are treated as CC0-style demo assets.

The scene also includes local GLB furniture and decor placeholders for sofas, lamps, tables, rugs, plants, mugs, and accessories.

No audio is included in this example.
