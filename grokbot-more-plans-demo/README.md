# Grok Bot — More Plans

A 12.48-second character spot for Grok Bot — bouncing shapes build a stacked tower, one headline, final lockup.

**Built with the [Editframe](https://editframe.com) React SDK** · 1920×1080 · 30fps

---

## Quick start

From the examples repo root:

```bash
npm install
npm start
npm run render:grokbot-more-plans-demo  # -> grokbot-more-plans-demo/output/demo.mp4
```

The music bed plays as a native `<Audio>` element on the composition timeline — no post-render mux step. Audio lives in `src/assets/` — see [CREDITS.md](CREDITS.md) for license details.

---

## Scene timeline

| Time | Scene | What happens |
|---|---|---|
| `0 – 7.30s` | **Bounce** | All eight shapes enter — black/orange balls, teal/red/brown/stone/dark clovers, blue tip ball — tower builds and sways |
| `7.30 – 10.30s` | **Headline** | "Grok Bot, now on more plans" pops in while remaining shapes exit; black ball persists alone |
| `10.30 – 12.48s` | **Lockup** | "Grok" and "Bot" slide into the final lockup alongside the black ball |
