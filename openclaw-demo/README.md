# OpenClaw - From Message to Done

A 30-second product demo of OpenClaw turning one chat message into completed work across mail, calendar, GitHub, and local device state.

Built with the [Editframe](https://editframe.com) React SDK. 1920x1080 at 30fps.

## Quick start

```bash
npm install
npm run render
```

The rendered video is saved to `output/demo.mp4`.

This build is silent. See [CREDITS.md](CREDITS.md) for asset and font notes.
