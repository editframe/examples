# Brand Rules - OpenClaw

Derived from the live OpenClaw site and approved creative brief.

## Palette

| Token | Value | Usage |
| --- | --- | --- |
| `bg-deep` | `#050810` | Primary background |
| `bg-surface` | `#0a0f1a` | Desktop and app surfaces |
| `bg-elevated` | `#111827` | Foreground panels |
| `coral-bright` | `#ff4d4d` | OpenClaw mark and decisive action |
| `coral-mid` | `#e63946` | Secondary coral motion accent |
| `coral-dark` | `#991b1b` | Logo gradient end |
| `cyan-bright` | `#00e5cc` | Completion, route, status |
| `cyan-mid` | `#14b8a6` | Secondary status |
| `text-primary` | `#f0f4ff` | Primary text |
| `text-secondary` | `#8892b0` | Supporting text |
| `text-muted` | `#5a6480` | Metadata |

## Typography

- Display: `Clash Display`, fallback `system-ui, sans-serif`
- Body: `Satoshi`, fallback `system-ui, sans-serif`
- Mono: `SF Mono`, `Fira Code`, `JetBrains Mono`, `monospace`

## Motion

- Precise and tool-like.
- One focal change at a time.
- Route lines show causality from the original message to completed work.
- Completion is shown with UI state changes, not narrated feature claims.

## Logo

Use the actual OpenClaw SVG path geometry from `https://openclaw.ai/favicon.svg`.
