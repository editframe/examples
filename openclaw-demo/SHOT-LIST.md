# Shot List - OpenClaw Demo

## Scene 1: One Message, Many Stakes - 0s to 8s

- Dark OpenClaw desktop environment.
- OpenClaw header stays anchored at top.
- Main chat window types: "Can you clear my morning and prep the release follow-up?"
- Send button pulses once.
- Capability chips appear: Mail, Calendar, GitHub, Reminders, Local.
- Routing map resolves from chat to gateway to device to tools.

## Scene 2: Work Leaves The Chat - 8s to 22s

- Chat pins to the left.
- Signal lines route outward from the original request.
- Mail surface appears first: unread count drops, replies draft and send.
- Calendar surface appears next: conflict moves, release prep block appears.
- GitHub surface appears: release follow-up issue opens with checklist.
- Local surface appears: device route, context, and tool availability confirm.

## Scene 3: Back To Done - 22s to 30s

- Work surfaces collapse back into the chat receipt.
- OpenClaw types the completed-work response.
- Four completion items check in.
- Final card resolves to OpenClaw mark and "The AI that actually does things."
