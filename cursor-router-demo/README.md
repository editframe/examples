# Cursor Router

A 22-second product demo for Cursor Router — white, typographic, diagram-led.

**Built with the [Editframe](https://editframe.com) React SDK** · 1920×1080 · 30fps

---

## Quick start

From the examples repo root:

```bash
npm install
npm start
npm run render:cursor-router-demo  # -> cursor-router-demo/output/demo.mp4
```

This demo is silent by design — there is no `<Audio>` on the timeline. Bundled fonts and imagery are documented in [CREDITS.md](CREDITS.md).
