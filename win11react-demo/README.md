# Win11React — Intro Film

An 18-second landscape intro for [Win11React](https://win11.blueedge.me), rebuilt as an Editframe composition.

The film moves through the product’s strongest visual story: lock screen, interactive desktop, centered taskbar and Start menu, then a project card. It uses a small, organized set of media taken from the live project’s public asset set; the interface itself is recreated in React/CSS for crisp rendering at 1920×1080.

## Render

```bash
npm run render:win11react-demo
```

Output: `win11react-demo/output/demo.mp4`.

## Media

`src/assets/reference/` contains the wallpaper, lock-screen image, boot mark, and application icons used by the composition. See [CREDITS.md](CREDITS.md) for source URLs and attribution notes.
